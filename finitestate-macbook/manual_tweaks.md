# iTerm2

## Emacs Meta

In terminal emacs (inside debian VM), option + x gets interpreted as the approximately equal symbol. To have option act as meta, tell iTerm2 to map left option to Esc+.

1. Open iTerm2 preferences
2. Click on Profiles
3. Click on Keys
4. Under General, find the Left Option key setting
5. Select Esc+ (The Meta didn't work)
